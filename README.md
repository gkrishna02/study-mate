# StudyMate — Smart Study Resource Finder

StudyMate is a web application designed to help students quickly find verified notes, practical files, and study materials without searching through multiple WhatsApp groups.

## Features
- Search for resources by subject and year.
- Upload verified notes (PDF/Images).
- Built-in usage tracking (time-to-find, clicks, success rate) for statistical validation.
- Responsive frontend for mobile and desktop.

## Prerequisites
- Python 3.8+
- pip
